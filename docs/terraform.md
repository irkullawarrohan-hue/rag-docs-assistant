# Terraform

Terraform is an Infrastructure as Code tool used to create and manage infrastructure through configuration files.

Terraform configuration files use the .tf file extension.

The terraform init command initializes a Terraform working directory.

The terraform plan command shows the changes Terraform intends to make.

The terraform apply command creates or updates infrastructure.

Terraform state keeps track of the infrastructure managed by Terraform.

Terraform modules allow infrastructure configurations to be organized into reusable components.

Terraform can manage cloud infrastructure such as AWS VPCs, subnets, security groups, and EC2 instances.
