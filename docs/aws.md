# AWS

Amazon Web Services is a cloud platform that provides infrastructure and managed services.

Amazon EC2 provides virtual servers in the cloud.

Amazon S3 provides object storage for files and data.

Amazon VPC provides an isolated virtual network for AWS resources.

IAM controls access to AWS resources through users, roles, and policies.

Security Groups act as virtual firewalls for resources such as EC2 instances.

Amazon EKS is a managed Kubernetes service.

Amazon CloudWatch is used to collect metrics, logs, and monitoring information from AWS resources.

AWS resources can be managed manually through the AWS Console, command-line tools, or Infrastructure as Code tools such as Terraform.
